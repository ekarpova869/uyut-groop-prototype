# Уют Groop — цифровой гостевой сервис (прототип)

Учебный прототип по дисциплине «Разработка бизнес-требований и ФТТ», дополнительная практическая работа (vibe coding).

Гость заказывает уборку, полотенца или вызывает инженера с телефона и видит статус запроса; сотрудник службы принимает и выполняет запрос; ресепшен видит просроченные запросы.

**Как показывать:** откройте сайт в двух окнах браузера — в одном «Я гость», в другом «Я сотрудник». Изменения появляются в обоих окнах сразу.

- `index.html` — прототип (одна страница, без сервера; данные хранятся в браузере)
- `TASK.md` — постановка задачи и требования для AI-инструмента
- `LOG.md` — журнал итераций с AI
